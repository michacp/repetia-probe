Configurar el AC-5000 para esta prueba

    
  

  

    
Valores que debes usar

    

      
Server IP: cargando…

      
Server Port: …

    

    
Si hay varias IP, usa la de la misma red (misma subred) que el terminal. Puerto por defecto: 9870 (servidor UNIS) o 2201 (servidor Access).


    
1. Entrar al menú

    
    
      
  1. Toca con la mano la zona del dibujo “CARD” para que se iluminen las teclas.
    2. 
      
  2. Mantén ENT pulsada 2 segundos o más.
    3. 
      
  3. Si hay un administrador registrado, pide verificación (huella, tarjeta o contraseña).
    4. 
      
  4. Con las teclas numéricas entras a cada submenú.
    5. 
    


    
2. Red → IP (2 → 1)

    
    
      
  1. Elige 1 Static IP.
    2. 
      
  2. IP Address: una libre de la misma subred que este equipo. Se borra con F4 y se escribe en bloques de 3 dígitos; los puntos salen solos. Ej.: 192 168 010 050 da 192.168.10.50.
    3. 
      
  3. Subnet Mask (normalmente 255 255 255 000) y Gateway (el router). ENT mueve entre campos.
    4. 
      
  4. Para guardar y volver: mantén ENT 2 s.
    5. 
    


    
3. Red → Server IP (2 → 2)

    
    
      
  1. Server IP: la IP de este equipo (arriba).
    2. 
      
  2. Server Port: el puerto de arriba (ENT para pasar al campo).
    3. 
      
  3. Mantén ENT 2 s para aplicar.
    4. 
    


    
4. Red → Terminal ID (2 → 3)

    
    
      
  • Terminal ID: 1.
    • 
      
  • Authentication: 2. Terminal/Server (valor por defecto). En esta opción el terminal autentica por su cuenta y manda el resultado al servidor.
    • 
    


    
5. Guardar

    
    
      
  1. Vuelve al menú principal con F4.
    2. 
      
  2. Pulsa F4 otra vez en el menú principal: aparece “Save?”.
    3. 
      
  3. Elige 1 Yes y pulsa ENT.
    4. 
    

    
Si no guardas, los cambios se pierden al salir.


    
6. Comprobar

    
    
      
  • En la pantalla del terminal, el icono de red (arriba a la derecha) pasa de “cable conectado” a “conectado con el servidor”.
    • 
      
  • En esta página debe aparecer una tarjeta entrante con la IP del terminal.
    • 
      
  • Si no aparece: usa el botón Ping con la IP del terminal, revisa el firewall (puertos abiertos de entrada) y que ambos equipos estén en la misma red.
    • 
      
  • Revisa también Información → Network Info en el terminal para ver la IP, el servidor y el puerto que realmente guardó.
    •
